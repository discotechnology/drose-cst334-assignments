# CST 334 Programming Assignments

This repository contains programming assignments completed for **CST 334**. Each assignment is organized in its own package so that its source code, supporting files, and documentation remain together.

## Repository Organization

Every package represents one programming assignment. Packages may include:

- Source code and related project files
- Input files, test cases, or other supporting materials
- A package-level `README.md` with detailed assignment information

The package README files explain the assignment specifications, required behavior, implementation details, and any instructions needed to build or run the program.

## Purpose

This repository serves as a central collection of CST 334 programming work. Organizing each assignment as an independent package makes it easier to review the requirements, understand the implementation, and run the corresponding program.
